# NotesDesk Client — NAS API 瘦客户端

连接群晖 / 本机 `notes-desk-server` 的桌面浮窗，**不运行本地钉钉桥**，数据与提醒均在 NAS 端处理。

## 目录

| 子目录 | 平台 | 说明 |
|--------|------|------|
| [`mac/`](mac/) | macOS 13+ | Swift + SwiftUI 浮窗 |
| [`win/`](win/) | Windows 10+ | WPF + 系统托盘 |

## 前置条件

1. NAS 已运行 `notes-desk-server`（见 [安装与配置指南](../notes-desk-server/docs/安装与配置指南.md)）
2. 浏览器可访问 `http://<NAS_IP>:17887/health` 返回 `{"ok":true,...}`
3. 客户端 **设置** 填写 Web 用户名/密码（默认 `admin`/`admin`），或填写与 Docker 一致的 `NOTESDESK_TOKEN`

> 仅填服务器地址会出现 `HTTP 401 Unauthorized`，因 `/api/*` 需登录或 Token。

## macOS

开发运行：

```bash
cd notes-desk-client/mac
./run.sh
```

打包 DMG（安装包）：

```bash
cd notes-desk-client/mac
chmod +x scripts/*.sh
./scripts/package-dmg.sh
# 产物：dist/NotesDeskClient-0.1.0.dmg
```

首次在 **设置** 中填写：

- **服务器地址**：如 `http://192.168.1.100:17887`（不要末尾斜杠）
- **Web 用户名/密码**：默认 `admin` / `admin`（登录后建议在 Web 改密码）
- **API Token**（可选）：若 Docker 设置了 `NOTESDESK_TOKEN`，可只填 Token 不填密码

设置面板与 Web 管理页功能对齐，包含四个分区：

| 分区 | 功能 |
|------|------|
| 连接 | NAS 地址、登录、本地偏好 |
| AI 大模型 | 启用开关、Base URL、API Key、模型、测试连接 |
| 分析定时 | 周/月/年定时分析、钉钉推送、提醒延迟 |
| 统计分析 | 周期统计、手动运行 AI 分析、查看报告 |

菜单栏 **AI 统计与分析…** 可直达统计页。

Windows 客户端已对齐 Mac：按日月历（三色点）、搜索、评论、Web 登录。

```bash
cd notes-desk-client/win
dotnet run --project NotesDeskClient.Win
```

或使用 `run.bat`。设置中填写服务器地址 + 用户名/密码（默认 admin/admin），或 API Token。

## 架构

```
手机钉钉 → notes-desk-server (Docker, 7×24)
                ├── SQLite
                ├── 钉钉 Stream 桥
                └── 到期提醒

Mac/Win notes-desk-client
    └── HTTP 轮询 + 操作 API
        GET  /health
        GET  /api/tasks?date=&q=
        GET  /api/tasks/calendar-days?month=
        GET/POST/PATCH/DELETE /api/tasks/:id/comments
        PATCH /api/tasks/:id
        POST /ingest
        DELETE /api/tasks/completed
```

详细验收口径见服务端：[需求说明](../notes-desk-server/docs/需求说明.md) · [开发进度](../notes-desk-server/docs/开发进度.md)。

## 已支持（Mac / Windows，对齐 notes-desk-server）

| 能力 | 说明 |
|------|------|
| 按日筛选 | 月历点选；`created ∪ due`（上海时区） |
| 月历色点 | 黄=新建 · 红=未完成 · 绿=已完成（可并存） |
| 搜索 | 输入即搜；有关键词时全库（正文+评论，含已完成） |
| 评论 | 任务行打开评论；增删改 |
| 多条创建 | 输入框可换行，服务端按规则拆成多条 |
| 登录 | Web 用户名/密码或 API Token |

Mac / Windows 均已支持上表能力。
