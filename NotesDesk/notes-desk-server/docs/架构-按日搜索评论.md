# 架构与 API 设计 — 按日 / 搜索 / 评论 / 月历色点

> 状态：**已定稿并落地**（2026-07-18）  
> 配套：[需求说明](./需求说明.md) · [开发进度](./开发进度.md)

---

## 1. 总体方案

```
Web / Mac / Win
        │
        ▼
notes-desk-server
  GET  /api/tasks?date=&q=&status=&includeCompleted=&view=
  GET  /api/tasks/calendar-days?month=YYYY-MM
  GET/POST/PATCH/DELETE  /api/tasks/:id/comments[/:cid]
  POST /ingest
        │
        ▼
SQLite
  tasks
  task_comments
  task_events（生命周期，非用户评论）
```

鉴权：session Cookie / `NOTESDESK_TOKEN`；评论与列表同级保护。`/ingest` 仍可不经 Web session（钉钉桥 / 本机快速添加）。

## 2. 数据库

### 2.1 `migrations/002_task_comments.sql`

```sql
CREATE TABLE IF NOT EXISTS task_comments (
  id TEXT PRIMARY KEY,
  task_id TEXT NOT NULL,
  body TEXT NOT NULL,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL,
  FOREIGN KEY (task_id) REFERENCES tasks(id) ON DELETE CASCADE
);
CREATE INDEX IF NOT EXISTS idx_comments_task ON task_comments(task_id);
CREATE INDEX IF NOT EXISTS idx_comments_created ON task_comments(created_at);
```

### 2.2 日界

`TIMEZONE=Asia/Shanghai`：`date=YYYY-MM-DD` → 该自然日的 `created_at` 或 `due_date`（按日键比较）。

## 3. API

### 3.1 `GET /api/tasks`

| Query | 说明 |
|-------|------|
| `date` | `YYYY-MM-DD`，created ∪ due |
| `q` | 关键词；**非空时全库搜**（正文 ∪ 评论，含已完成），**忽略** `date`/`view`/`status=incomplete` |
| `status` | `incomplete` \| `completed`（无 `q` 时生效） |
| `view=today` | 今日 + 仅未完成（无 `q`、无显式 `date` 时） |
| `includeCompleted` | 有 `date` 且无 `q` 时默认 `true` |

响应：

```json
{
  "tasks": [ /* DeskTask[] */ ],
  "commentCounts": { "<taskId>": 2 }
}
```

### 3.2 `GET /api/tasks/calendar-days?month=YYYY-MM`

```json
{
  "created": { "2026-07-18": 4 },
  "incomplete": { "2026-07-18": 3 },
  "completed": { "2026-07-17": 1 }
}
```

| 字段 | 色点 | 规则 |
|------|------|------|
| `created` | 黄 | `createdAt` 落在该日 |
| `incomplete` | 红 | 未完成 ∧（created ∨ due 落在该日） |
| `completed` | 绿 | 已完成 ∧（created ∨ due 落在该日） |

同一日可同时有黄+红+绿。

### 3.3 评论

| 方法 | 路径 |
|------|------|
| GET | `/api/tasks/:id/comments` |
| POST | `/api/tasks/:id/comments` `{ "body" }` |
| PATCH | `/api/tasks/:id/comments/:cid` `{ "body" }` |
| DELETE | `/api/tasks/:id/comments/:cid` |

### 3.4 多条创建

`POST /ingest` / `POST /api/tasks`：`splitTaskLines` 后批量创建；成功时 `action: "create_batch"`。

## 5. 客户端约定

1. **有搜索词**：只传 `q`（+ 鉴权），不传 `date`；标题显示「搜索「…」」。  
2. **无搜索、有选日**：传 `date`，展示该日任务（含完成）。  
3. **月历**：切月时拉 `calendar-days`；任务变更后刷新色点。  
4. **今日视图**（Mac `viewMode=today`）：无搜索时客户端勿再二次裁剪搜索结果。

## 6. 与早期草案差异（已定）

| 早期草案 | 现口径 |
|----------|--------|
| `q` 可与 `date` 组合缩小 | 有 `q` **不**与日/视图组合，全库搜 |
| 搜索仅 `text` | 正文 + 评论 |
| 原生 date input | 内嵌月历默认展开 |
| 无色点 | 黄/红/绿可并存 |
| Win 延后 | Win 已对齐 |
