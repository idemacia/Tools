# NotesDesk Server — 需求说明（按日 / 搜索 / 评论 / 月历色点）

> 状态：**已实现**（2026-07-18 迭代验收口径如下）  
> 范围：`notes-desk-server` + Web 管理页 + Mac/Win 瘦客户端（`notes-desk-client`）  
> **不含**：`notes-desk-widget` / `notes-desk-panel`（苹果备忘录工具，不连 NAS）

---

## 1. 背景

任务列表原先仅有 `view=today`（今天 + 仅未完成），缺少按任意日回顾、关键词查找与事项级复盘。本迭代补齐后，并在联调中修正搜索被日期挡住、日历交互与色点语义等问题。

### 2.1 目标

| ID | 需求 | 优先级 | 状态 |
|----|------|--------|------|
| F-D01 | 选择任意日期，展示「当日相关」事项（created ∪ due） | P0 | 已完成 |

- `completed_at` 落在当日不算「按日命中」（本迭代不做）

## 3. 功能细则

### 3.1 按日查看（F-D01）

**「当日相关」**（`Asia/Shanghai` 自然日 `YYYY-MM-DD`）：

1. `created_at` 落在该日，或  
2. `due_date` 落在该日  

| 参数 | 含义 | 默认 |
|------|------|------|
| `date` | 按日过滤 | — |
| `includeCompleted` | 是否含已完成 | `true`（有 `date` 时） |
| `view=today` | 兼容：今日 + **仅未完成** | — |

**UI：** 内嵌月历（默认展开，无需再点原生「年月日」字段）；支持今天 / 清除；标题显示日期与条数。

### 3.2 搜索（F-D02）

- 匹配 **任务正文** 与 **评论正文**（不区分大小写子串）
- **有非空 `q` 时：全库检索**，忽略 `date` / `view=today` / 「仅未完成」视图，并包含已完成  
  （避免「搜牛奶却看不到买牛奶」——事项不在所选日时被裁掉）
- 无 `q` 时：按当前日期筛选或未完成视图正常工作
- UI：输入即搜（约 250ms 防抖）；清空后恢复列表

### 3.3 评论 / 复盘（F-D03）

- 每任务多条评论；字段：`body`、`createdAt`、`updatedAt`
- API：`GET/POST/PATCH/DELETE /api/tasks/:id/comments[/:cid]`
- 列表附带 `commentCounts`
- UI：详情 / Sheet；支持增删改；行上可显示评论数

### 3.4 月历色点（F-D04）

对日历日 `D`（可并存，**一格最多三色点**）：

| 色 | 含义 | 规则 |
|----|------|------|
| **黄** | 该日有新建 | `createdAt` ∈ `D` |
| **红** | 该日有未完成 | 未完成且（`createdAt` ∈ `D` 或 `dueDate` ∈ `D`） |
| **绿** | 该日有已完成 | 已完成且（`createdAt` ∈ `D` 或 `dueDate` ∈ `D`） |

悬停可显示数量。绿点语义为「关联到该日且已完成」，**不是**「`completedAt` 落在该日」（若以后要改需单独定）。

API：`GET /api/tasks/calendar-days?month=YYYY-MM`  
→ `{ created, incomplete, completed }`（各为 `Record<YYYY-MM-DD, number>`）

### 3.5 多条拆分（F-D06）

`POST /ingest` 与手动创建：按换行、`；`、`|`、`1、`/`1.`/`(1)` 等规则拆成多条（本地规则，非 LLM）。

---

## 5. 验收标准

1. 选某日：仅 created∪due 落在该日；默认含已完成。  
2. `view=today`：今天 + 仅未完成（与升级前一致）。  
3. 搜索「牛奶」能命中「买牛奶」，即使当前选了别的日期；评论关键词也能命中任务。  
4. 月历默认可见；有活动的日子显示对应黄/红/绿点（可并存）。  
5. 评论可增删改；列表有 `commentCounts`。  
6. 换行多条 ingest 生成多条任务。  
7. Web、Mac、Win 均可完成上述操作；升级镜像后旧 `data/` 自动迁移。
